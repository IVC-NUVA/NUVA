Code systems

Direct maps

Direct maps are simple CSV files with the external code and NUVA code as first two columns, optionally a label in third column.

To avoid unwanted conversions for numbers, the external code must be prefixed with the code system name.

The first row contains titles with column 1 being the code system name:

CVX,NUVA,label

Each subsequent row has a structure such as:
CVX-35,VAC0132,"Tetanus vaccine, unspecified"

For countries where Excel uses a semicolon for CSV, use LibreOffice instead.

The currently published direct maps can be downloaded from the NUVA GitHub repository.
