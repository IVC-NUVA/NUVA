# Files tab
The files tab is used for file servicing:
- Creating a local backup of the [workfile](f_workfile.md) under edition.
- Restoring a local backup.
- Resetting all vaccines and valences to their reference values. All work done and not backuped is then lost.
- Preparing the draft [unit files](f_unitfile.md) of vaccines and valences for submission.
