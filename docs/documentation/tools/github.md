# The GitHub repository #
The GitHub platform is the management repository for producing, delivering, historisizing all NUVA artefacts.

This page will not restate all the GitHub features, but give specific information on its use.

## GitHub files structure
The GitHub files are organised as follows:
```mermaid
---

  treeView:
    showIcons: true

Exports/        ## Artefacts produced from the sources
  CSV/          ## Flat files
    nuva_vaccines_xx.csv
    nuva_valences_xx.csv	
  RDF/          ## RDF graphs
    nuva_core.ttl
    nuva_full.ttl
    nuva_xx.ttl     ## per language
.github/        ## GitHub actions
```
## Source files
### Unit files
The [unit files](f_unitfile.md) describe individual concepts for vaccines and valences. 

They are published by the NUVA core maintener.

Having a dedicated file for each concept allows to retrieve the history of changes on this specific concept using the GitHub `History` button.

Each update of one or several of these files triggers the [GitHub actions](github_actions.md) that will produce the NUVA artifacts.

### Translations
The translations folder contains the [language files](f_langfile.html).

The English language file is generated by the [GitHub actions](github_actions.md) when unit files are updated.

The other language files are produced from [Weblate](weblate.md) by language contributors.
### Alignments
The [alignment files](f_alignment.md) are provided by alignment contributors. They are reused only for some exports ([RDF full export](f_rdffile.md)).
## Generated files
### Consolidated core data
[Unit files](f_unitfile.md) allow to track easily changes per concept but are not very convenient for tools using the NUVA, including the online [NUVA editor](editor.md).

The [GitHub actions](github_actions.md) generates a reference [workfile](f_worfile.md) at `docs/data/nuvadata.json` each time the unit files are updated.

### Exports
Further exports are generated when the source files are changed: 
  - [Flat files](f_flatfile.md) of vaccines and valences, per language.
  - [RDF graphs](f_rdffile.md).
