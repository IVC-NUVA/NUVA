# NUVA layers
The NUVA core concept serve as an anchor for complements provided by community members.

NUVA users will fetch the layers that correspond to their needs, such as:
 - [language layers](language_layers.md) for the localization of the concepts labels, comments or shorthand notations with the languages used in the jurisdiction of the user.
 - [alignment layers](alignment_layers.md) for the code systems used locally.
 
 Beside these, further layers could be created, for example for the local availabity date, age range for administration, or reimbursement rates for vaccines.
