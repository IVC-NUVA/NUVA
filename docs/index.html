NUVA browser usage

This site presents the current core content of the NUVA terminology.

It is automatically updated on each NUVA update in the GitHub repository.

Vaccines view

The Vaccines view presents all the NUVA vaccine concepts, with for each vaccine the list of its valences.

Valences are represented with the usual shorthand notation. You can see more detail by hovering over the valence tag.

Vaccines can be edited or created. Modified vaccines are presented in bold.

Valences view

The Valences view presents the hierarchy of valences.

The terminal (most precise) valences are displayed in green.

The aggregated valences are displayed in black. You can fold or unfold them by clicking on their description.

Valences can be edited or created. Modified valences are presented in bold.

Families view

Families presents the abstract vaccines, and each abstract vaccine can be unfolded to the matching real vaccines.

Selection

You can include a valence in the selection:

  • By clicking on a valence tag in the Vaccines view
  • By ticking the checkbox for a valence in the Valences view
  • By clicking the select button for a family in the Family view (the family valences will be selected)

The selected valences are visible in the Selected section of the left side menu and as checkboxes in the valences tree. The parents valences for a selected valence are also checked, but with a greyed checkbox.

Filtering

Once valences have been selected, they can be assigned to the filter.

The filter has impact in views:

  • Only vaccines with ALL of the selected valences (or a more precise version of the selected ones) are displayed
  • Only valences with ANY of the selected valences, their parents and children, are displayed
  • Only families will ALL of the selected valences (or a more precise version) are displayed

Files view

The current modifications are kept only while the browser is open. They can be saved to a backup file and restored later.

New unit files can be generated for modified Valences and Vaccines. These files can then be submitted to the NUVA Github in order to be incorporated into a next release.
