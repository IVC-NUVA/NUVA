Import source codes

Import a CSV file containing the external codes to align. Required fields are Code and Label; Description and Notes are optional. Any other columns are kept with the record.

Start from an existing alignment

Initialize or extend this workspace from a direct map already used by the Code Systems tools, such as CVX2nuva.csv. The first row is CSID,NUVA,label; each following row is EXTCODE,VACnnnn,"label". Matching records are created with status imported, their NUVA vaccine retained, and their valences derived from that vaccine - they still need review, but are not treated as newly reviewed.
