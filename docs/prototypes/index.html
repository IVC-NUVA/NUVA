NUVA alignment prototypes

Several deliberately different explorations of the code-system alignment workflow, built to be clicked through and reacted to. None of them is a recommendation. Each one keeps its own work in browser storage, separate from the others and from the main editor.

Loupe

Direction A: single screen, no tab-switching

Everything needed to align one code on one screen: the code, the candidate vaccine and its valences side by side.

Passport Control

Direction C: guided, with tracked status

One step at a time on a laptop-width screen, with per-code status, confidence and petitions for missing NUVA content.
